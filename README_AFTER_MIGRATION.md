# Project na migratie

Deze projectmap is opgeschoond zodat `WebapplicatieProjectIWAVersie4` niet meer nodig is.

Belangrijk:
- De webapp draait vanuit `wap-app`.
- De oude top-level dashboardmap is verwijderd.
- Oude generator-configuratiebestanden zijn verwijderd.
- De API-ingest endpoints in Laravel zijn behouden, zodat externe data-aanlevering later nog steeds mogelijk is.

Start lokaal vanuit `wap-app` nadat Composer dependencies zijn geïnstalleerd.
